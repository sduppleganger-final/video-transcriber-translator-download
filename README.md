# Video Transcriber & Translator downloads

Official Windows and Mac downloads for Video Transcriber & Translator.

- [Public download page](https://sduppleganger-final.github.io/video-transcriber-translator-download/)
- [Windows and Mac 1.0.8 release](https://github.com/sduppleganger-final/video-transcriber-translator-download/releases/tag/v1.0.8)

The app works with local video and audio files. Windows and Mac 1.0.8 add a persistent private custom dictionary with manually preferred terms, exact replacements, and learned suggestions only after the same unambiguous one-word correction has been made three times across sessions. Uploaded SRT files never train or change the dictionary automatically. Both platforms can attach an existing UTF-8 SRT file without modifying the source, offer the optional Hebrew-optimized Ivrit.ai engine, bundle Hy-MT and QuickMT translation, and export reviewed DOCX/PDF transcripts. The unsigned/unnotarized native Apple Silicon and Intel Mac 1.0.8 builds require the bilingual Gatekeeper instructions on the public page.

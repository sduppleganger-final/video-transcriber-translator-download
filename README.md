# Video Transcriber & Translator downloads

Official Windows and Mac downloads for Video Transcriber & Translator.

- [Public download page](https://sduppleganger-final.github.io/video-transcriber-translator-download/)
- [Windows 1.0.7 release](https://github.com/sduppleganger-final/video-transcriber-translator-download/releases/tag/v1.0.7)
- [Mac 1.0.7 release](https://github.com/sduppleganger-final/video-transcriber-translator-download/releases/tag/v1.0.7-mac)

The app works with local video and audio files. Windows and Mac 1.0.7 can attach an existing UTF-8 SRT file to a video without modifying the source, offer the optional Hebrew-optimized Ivrit.ai engine, bundle Hy-MT and QuickMT translation, and export reviewed DOCX/PDF transcripts. The unsigned/unnotarized native Apple Silicon and Intel Mac 1.0.7 builds require the bilingual Gatekeeper instructions on the public page.

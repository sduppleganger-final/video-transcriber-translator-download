# Video Transcriber & Translator downloads

Official Windows and Mac downloads for Video Transcriber & Translator.

- [Public download page](https://sduppleganger-final.github.io/video-transcriber-translator-download/)
- [Windows 1.0.7 release](https://github.com/sduppleganger-final/video-transcriber-translator-download/releases/tag/v1.0.7)
- [Mac 1.0.3 release](https://github.com/sduppleganger-final/video-transcriber-translator-download/releases/tag/v1.0.3-mac)

The app works with local video and audio files. Windows 1.0.7 can attach an existing UTF-8 SRT file to a video without modifying the source, adds the optional Hebrew-optimized Ivrit.ai engine, and exports reviewed DOCX/PDF transcripts. Windows and native Apple Silicon/Intel Mac packages include their default offline transcription, translation, and media tools. The unsigned/unnotarized Mac 1.0.3 builds require the bilingual Gatekeeper instructions on the public page and do not yet include the Windows 1.0.7 additions.

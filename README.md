# Video Transcriber & Translator downloads

Official Windows and Mac downloads for Video Transcriber & Translator.

- [Public download page](https://sduppleganger-final.github.io/video-transcriber-translator-download/)
- [Windows and Mac 1.0.12 release](https://github.com/sduppleganger-final/video-transcriber-translator-download/releases/tag/v1.0.12)

The app works with local video and audio files. Windows and Mac 1.0.12 keep manually preferred terms, exact replacements, and learned suggestions only for the current session; a suggestion appears only after the same unambiguous one-word correction has been made three times during that session. Uploaded SRT files never train or change the dictionary automatically. Both platforms can attach an existing UTF-8 SRT file without modifying the source, offer the optional Hebrew-optimized Ivrit.ai engine, bundle Hy-MT and QuickMT translation, and export reviewed DOCX/PDF transcripts. They also provide optional user-key Gemini proofreading that sends only the complete current translated SRT to Google after explicit action; media stays local. The unsigned/unnotarized native Apple Silicon and Intel Mac 1.0.12 builds require the bilingual Gatekeeper instructions on the public page.
